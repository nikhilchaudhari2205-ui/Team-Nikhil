# Team-Nikhil
Hackathon ID: [AZIS-97ZERH]

## Track
SkillSwap / Creator Economy Marketplace

## Tech Stack
- HTML5, Vanilla JavaScript
- Tailwind CSS (via CDN)
- Lucide Icons
- LocalStorage for persistence

## Run Steps
1. Clone this repository or open the project folder.
2. Open `index.html` directly in any modern web browser.
3. Alternatively, visit the live deployment at: https://sparkgig.vercel.app

## Test Credentials / Access
No authentication required. Evaluators can switch freely between 'Client' and 'Creator' roles directly in the top navigation bar.
